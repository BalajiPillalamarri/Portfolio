01 PNC Financial Services

Shared Document AI service

The foundation under every PNC agent: PyMuPDF rendering, PaddleOCR detection and recognition, layout detection, LayoutReader (LayoutLMv3) reading order and VLM table and chart extraction — emitted as anchored markdown plus a chunk manifest, so every value traces back to a highlighted crop of its source.

  • 94% F1
  • 20+ doc types
  • 1,000+ docs/day
  • −70% manual processing
Under the hood
  • Confidence-gated OCR: low-confidence reads are flagged for review, never passed downstream silently.
  • First-page document-type tagging into a Pydantic enum, with Guardrails rejecting off-schema labels; combined PDFs are split where the type changes.
  • A schema registry where each agent brings its own focused 8–12 field Pydantic schema — a new document type is one schema and one registry line.
  • Event-driven on AWS (S3 → EventBridge → Lambda) and reused by 6 production agents across lending, KYC and compliance.

02 PNC Financial Services

LangGraph loan processing agent

Prepares a complete, cited review package for every loan application — the officer still makes the call. The model extracts and narrates; Python validates and routes; the bank's audited APIs compute every financial metric.

  • 10K+ apps/month
  • <5 min P95
  • 2h → 30m officer review
  • 94% precision gate
Under the hood
  • Typed state graph: load → extract → validate → red-flag human checkpoint → three parallel MCP enrichment calls → cited summary → six-tab Excel report.
  • Deterministic cross-document checks (fuzzy + phonetic name match, income variance, recency, duplicates) that flag but never reject.
  • Redis checkpointing for pod-crash recovery and hours-long human pauses, with concurrent runs isolated by application ID.
  • A 1,000-case DeepEval golden set gates every change; LiteLLM falls back to Claude Sonnet during outages and rate limits.
LangGraphMCPRedisEKSDeepEvalLangSmithArize AI
